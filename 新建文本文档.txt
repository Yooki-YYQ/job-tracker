进入项目目录

cd D:\job-tracker


启动数据库

cd infra
docker-compose up -d


-d 表示后台运行。

这一步会启动 Postgres 和 Adminer。

你可以用 docker ps 确认容器在跑。

启动后端

cd ..\backend
npm run dev


这会启动 Express + Prisma API 服务。

测试 API

打开浏览器访问：

http://localhost:5000/health （检查服务是否正常）

PowerShell 插入测试用户：

Invoke-RestMethod -Method Post -Uri http://localhost:5000/api/users `
  -ContentType 'application/json' `
  -Body (@{ email='a@test.com'; password='123456' } | ConvertTo-Json)


用 Adminer 登录 (http://localhost:8080)，能看到 User 表数据。
